university-sync

university-sync は、開発者本人だけが使う個人用のツールです。本人の Google アカウントにある授業の課題・資料・メールを読み取り、本人のパソコン上のノートと本人の Google ドライブに整理します。一般の利用者向けのサービスではありません。

プライバシーポリシー

取得する情報：本人が許可した Google アカウントの、Google Classroom の授業・課題・提出状態・資料・お知らせ、Gmail のメッセージ（読み取りのみ）、Google ドライブのファイル（読み取りのみ）。

利用目的：本人の課題・締切・授業資料を整理し、本人の学習を助けるためだけに使います。

保存先：本人のパソコン上と、本人の Google ドライブ（このツールが作成したファイルのみ）。第三者のサーバーには保存しません。認証情報は本人のパソコンのキーチェーンに保存します。

第三者への提供：取得した情報を販売・共有・広告に利用することはありません。メール本文の一部は、課題情報を抽出するため、本人が契約する AI サービス（Anthropic の Claude）で処理することがあります。

削除：本人は Google アカウントの設定（サードパーティ製アプリのアクセス）からいつでもアクセス権を取り消せます。保存した情報は本人のパソコンと Google ドライブから削除できます。

Google API サービスのユーザーデータに関するポリシー：Google API から取得した情報の使用・転送は、限定的使用の要件を含む Google API Services User Data Policy に従います。
